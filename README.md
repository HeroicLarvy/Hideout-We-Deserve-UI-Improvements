# Hideout We Deserve - UI Improvements

The first in a series of hideout QoL and redesign mods. SPT 4.1.6

## What you get

- Hover over a hideout station to see its upgrade requirements, including item counts and the other stations or traders needed.
- See active crafts and their remaining time, or **Completed** when an item is ready to claim.
- Hide the bottom scroll bar.
- Open a station menu without zooming the camera.
- Marks items used by current and future hideout upgrade requirements.
- Mark ingredients for favorited hideout crafts with a separate toggle and color. The tooltip shows each crafted output and the hovered ingredient's owned/needed count.
- Organise a station's crafts into up to 5 folders from a fixed bar above the craft list. Drag a craft onto a folder or click the folder button beside its favorite icon to move it. Right-click a folder to rename, recolor or delete it. Only the selected folder's crafts are loaded.

## Install

Download `Hideout-We-Deserve-UI-Improvements-1.1.0.zip` from [Releases](https://github.com/HeroicLarvy/Hideout-We-Deserve-UI-Improvements/releases), then extract it into your SPT folder. The DLL is already inside `BepInEx\plugins`.
